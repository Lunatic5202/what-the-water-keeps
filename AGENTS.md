# Agent instructions

This is a Godot 4 game, "What the Water Keeps".

Before doing anything:

1. Read `README.md`. It has the rules, status, code layout and roadmap.
2. Read `docs/game-bible.md` for story, regions, bosses and tone.

Key rules (details in the README):

- Work on a branch, never on `main`. Keep commits small.
- Do not change the sign dialogue behaviour (E opens, walking
  away closes). It is intended.
- No buffs in this game, only debuffs.
- Do not invent lore. Follow the bible, or ask.
- Say plainly when something was not run or tested in Godot.
- Ask before big changes or remapping controls.
