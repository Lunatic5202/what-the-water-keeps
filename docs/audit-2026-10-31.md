## Confirmed issues fixed on this branch

### 1. Devour Spit double-damaged overlapping group members
Coin Guard and Cutlery Knight are members of both `enemy` and `boss`. Spit concatenated both groups and called `take_damage` twice on those targets.

**Fix:** `scripts/devour_style.gd` now de-duplicates targets by instance ID for each Spit.

### 2. Tempo Stopwatch wrote a property nobody read
The old fallback set `tempo_frozen` on any enemy without `fall_asleep()`. No script read that property, so those enemies continued moving and attacking.

**Fix:** Stopwatch now uses the existing `stun(seconds)` interface instead of writing an unused property.

### 3. Sloth enemies were missing from the shared enemy group
Sloth spawned its enemies into a local array but did not add them to the shared `enemy` group. Group-based skills such as Stopwatch could not discover these enemies.

**Fix:** `sloth.gd` now adds each spawned Sloth enemy to `enemy`.

### 4. Two Greed enemies did not implement the shared stun interface
Gilded Blossom and Penny Pip were in the `enemy` group but did not expose `stun(seconds)`, so Stopwatch could not freeze them.

**Fix:** both now implement a timed stun state and pause their behaviour while stunned.

### 5. Stuffed did not slow most alternate-style attacks\nGluttony set the shared `attack_speed_mod`, but only the base Lantern swing read it. Open Hand, Tempo, Devour and Lantern heavy timing ignored the modifier.\n\n**Fix:** apply the modifier to the active swing/windup durations in all four style implementations.\n\n### 6. Some style attacks/effects faced into climbable walls\nLantern heavy and several style guard/charge visuals read the player's raw `facing`, which intentionally points into a wall while clinging.\n\n**Fix:** use `player.attack_facing()` for those attack/effect directions, consistent with the player and Open Hand combat code.\n\n## Remaining findings / known gaps
